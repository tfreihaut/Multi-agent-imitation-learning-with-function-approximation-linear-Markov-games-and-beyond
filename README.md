# Multi-agent imitation learning with function approximation linear Markov games and beyond
The code for the corresponding paper: **Multi-agent imitation learning with function approximation: linear Markov games and beyond**

### Setup 
You can simply run the `setup.sh` file.
  
### Running the Connect4 experiments

```bash
python connect4_experiment.py
```

### Running the Tic-Tac-Toe experiments

```bash
python tictactoe_experiment.py
```

### Running the comparison of exploration algos

```bash
python dqnexplore_vs_deepunif.py
```

```bash
python chain_of_despair_experiment.py
```

### Running the linear experiments

```bash
python linear_bc_experiments.py
```

```bash
python linear_mail_experiments.py
```
